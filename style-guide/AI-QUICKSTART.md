# Region South AI Quick Start

Use the Region South Visual Style Guide in this folder.

Before generating a visual:
1. Ask the user to choose **Light Mode** or **Dark Mode** if not already specified.
2. Ask for **Source** and **Date** if missing; explicitly allow either to be omitted if not pertinent.
3. Confirm preliminary/embargo status when relevant.
4. Apply the locked subject and regional colors.
5. Use Poppins.
6. Define P+A, DFP, and SP somewhere in the same visual whenever those abbreviations appear.
7. Use authentic logo assets only; never redraw or approximate them.
8. Validate all data labels and claims before finalizing.

- Math: blue
- ELA: orange
- Science: green
