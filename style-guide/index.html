Brand Foundation

The Region South visual system is a presentation and communication framework designed to make instructional and data communications consistent, recognizable, student-centered, and aligned with LAUSD branding.

Priority: Data accuracy → Brand compliance → Readability → Subject identity → Student representation → Aesthetic polish.

Use official Region South and LAUSD assets only. Never redraw, recolor, distort, crop, or approximate official logos.

Light & Dark Modes

Light Mode

Best for print, dense charts, regional comparisons, and maximum color contrast.

Dark Mode

Best for presentations, executive dashboards, hero graphics, and student photography.

If the user has not specified a mode, prompt them to choose Light or Dark. If they ask for a recommendation, recommend one and obtain confirmation before generating.

Photography & Student Representation

Use authentic, age-appropriate, diverse students actively engaged in learning. Students are not decorative props.

Keep cross-panel axes consistent.

Terminology

Preferred Short form Rule
Proficient + Advanced P+A Do not display PoA in Region South-facing graphics.
Distance from Proficiency DFP Higher is better; 0 is proficiency.
Science Points SP Range 0–100; 65 is proficiency.
If P+A, DFP, or SP appears, define it somewhere in the same visual.

Data Visualization

  • P+A: higher is better; use percentage points for differences.
  • DFP: higher is better; show 0 = Proficiency when relevant; never reverse the axis.
  • SP: higher is better; 65 = Proficiency; never say “Proficiency Floor.”
  • Regional comparisons: South receives strongest visual emphasis, but comparison regions remain fully legible.
  • Cohort bars: subject color is primary; bar direction shows sign; green/red are secondary semantic cues only.

Metadata & Embargo

Source and date

If either is missing, prompt the user. Always offer the option to omit the item if it is not pertinent. Never invent a source or date.

Preliminary / embargoed data

Do not show restricted values or inferable endpoints. Use a direction-only or separate Preliminary Trend treatment.

Preferred wording: “Preliminary results remain embargoed and are shown only as a generalized trend.”
