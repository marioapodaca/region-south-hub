# Region South Examples Gallery

This gallery distinguishes between **Approved Examples** and **Legacy / Design References**.

## Status definitions

### Approved Example
A visual that has passed the current Region South compliance review:
- correct subject and regional colors
- correct terminology
- P+A / DFP / SP definitions where needed
- source/date resolved
- authentic logos or reserved logo placement
- correct display mode
- preliminary/embargo treatment verified
- data values checked

### Legacy / Design Reference
A useful visual reference created before the current rules were fully locked. It may demonstrate a strong layout or visual concept but should **not** be copied literally without applying the current guide.
