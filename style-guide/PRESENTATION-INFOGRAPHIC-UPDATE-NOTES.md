# Region South Style Guide Update — Presentation Infographic Style (v1.5)

## What was added
This update adds a new **Region South Presentation Infographic Style** for polished non-data visuals such as:
- presentation graphics
- instructional visuals
- frameworks
- overviews
- process graphics
- priorities graphics
- strategy summaries
- similar non-data infographics

## Key rules added
- Default to **16:9 landscape** for this style.
- In Dark Mode, use a **deep LAUSD Navy-based background** with subtle gradients and low-contrast subject-related patterns.
- Use a strong title hierarchy with a **subject-color primary title**.
- Use **one large subject-relevant hero icon** near the title.
- Use **2–4 balanced dark panels/cards** with thin accent outlines and clear hierarchy.
- Keep decorative elements **low-contrast, secondary, and nonessential**.
- Do **not** automatically add a footer, slogan, or extra branding.
- If a Region South visual is used as a style reference, transfer the **design language only**, not its text, slogans, logos, footer, or other content-specific elements.
- If the visual contains data, the data-visualization rules override decorative infographic styling.
