# Approved Visual References

Use the approved examples published in the Region South Visual Style Guide:

- Example gallery: https://marioapodaca.github.io/region-south-hub/style-guide/examples.html
- Full Style Guide: https://marioapodaca.github.io/region-south-hub/style-guide/

Select references that match the requested subject and presentation mode:

- Math — blue color family
- ELA — orange color family
- Science — green color family
- Light Mode — white or light neutral background
- Dark Mode — deep LAUSD Navy background
- Guideposts — three-column instructional framework
- Data infographic — accurate charts, labels, definitions, and disclosures
- Title slide — restrained content with strong hierarchy

When uploading reference images to ChatGPT, identify what each image demonstrates: layout, hierarchy, color, imagery, or data treatment. A reference image does not authorize reuse of inaccurate text, invented logos, or unrelated content.
