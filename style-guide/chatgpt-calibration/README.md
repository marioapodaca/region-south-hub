# ChatGPT Calibration Guide

GitHub Pages version of the Region South two-track guide for calibrating ChatGPT to create consistent visuals.

## Public URL

`https://marioapodaca.github.io/region-south-hub/style-guide/chatgpt-calibration/`

## Contents

- `index.html` — standalone webpage
- `styles.css` — responsive design and accessible animations
- `assets/RS-logo.png` — authentic Region South logo
- `downloads/` — complete calibration kit
- `references/` — individual instruction and validation files

The dragon uses CSS animation for a soft breathing glow, slow orbit motion, and occasional double blink. Animations are disabled when a visitor has reduced motion enabled.
