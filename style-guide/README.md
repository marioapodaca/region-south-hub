# Region South Visual Style Guide

This folder contains the Region South visual style system for human designers and AI tools.

## Start here
- `region-south-style-guide.md` — complete AI/human-readable rules
- `region-south-style-guide.yaml` — structured machine-readable specification
- `prompts.md` — reusable prompt library

## Core rule
Subject determines the color family. Region determines the shade.

## Display modes
Both Light Mode and Dark Mode are approved. The user must choose a mode before final visual generation.
