## Core design rules

- Subject determines the color family: Math uses blue, ELA uses orange, and Science uses green.
- Region determines the shade when regional comparisons are shown.
- Both Light Mode and Dark Mode are approved.
- Ask the user to select Light Mode or Dark Mode when no mode is specified.
- Ask for the source, download/data-as-of date, and preliminary or embargo status when applicable; allow the user to omit items that are not pertinent.
- Use grade-appropriate, representative student imagery. Use elementary students in elementary samples.
- Preserve authentic branding assets, proportions, colors, and placement.

## Maintenance guidance

- Maintain the authoritative Style Guide files only inside `style-guide/`.
- Do not create additional root-level copies of Style Guide files.
- Keep public filenames stable unless redirects are provided.
- Check internal links and downloads after every structural change.
- Update this README whenever files are added, renamed, moved, or removed.
- Allow GitHub Pages a few minutes to deploy after a commit, then hard-refresh the affected page.
