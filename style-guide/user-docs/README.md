# User-Shareable Documents

Two polished versions of the Region South Visual Style Guide are included here.

## Region-South-Visual-Style-Guide-User-Edition.pdf
Use this version when you want to:
- email the guide to staff
- post it in a shared folder
- distribute a read-only reference
- provide a consistent version that users should not edit

This is the recommended version for general distribution.

## Region-South-Visual-Style-Guide-User-Edition.docx
Use this version when you want to:
- edit wording
- add local notes
- update policies or examples
- produce a future revised PDF

Poppins is the preferred typeface. If Poppins is not installed on the computer opening the DOCX, Word may display a fallback font until Poppins is installed.

## Recommendation
Share the PDF with most users. Keep the DOCX as the editable master for future revisions.
