Light Mode + Dark Mode

Both modes are part of the same Region South design system. The user chooses the display mode before a final visual is generated.

Light Mode is preferred for print, dense charts, and detailed comparisons. Dark Mode is preferred for presentations, hero graphics, and student photography.
