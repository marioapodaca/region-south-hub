# START HERE — Downloads and What Each File Is For

## 1. `Region-South-Style-Guide-FINAL.zip`
**This is the only download required for the complete project.**

Use it to:
- keep a complete backup of the style-guide project;
- upload the guide to GitHub;
- share the entire system with another Region South team member.

After extracting it, open the `style-guide` folder. Do not flatten or rearrange its subfolders.

## 2. `style-guide/index.html`
Human-facing website home page.

Use it when:
- previewing the guide locally;
- publishing the guide with GitHub Pages.

Open it in a web browser for a local preview.

## 3. `style-guide/human-style-guide.md`
Human-readable source document for the visual standards.

Use it when:
- editing wording;
- reviewing the guide without the website;
- reusing the content in another documentation system.

## 4. `style-guide/region-south-style-guide.md`
Detailed AI-readable governing specification.

Use it as the main instruction reference for an AI system. This is the authoritative prose specification for AI behavior.

## 5. `style-guide/region-south-style-guide.yaml`
Machine-readable version of the specification.

Use it when:
- integrating the guide into a structured AI workflow;
- parsing rules programmatically;
- maintaining exact palettes and rule flags.

## 6. `style-guide/AI-QUICKSTART.md`
Short AI onboarding file.

Use it when an AI does not need the entire detailed guide in its initial prompt. It contains the rules that are most likely to affect generation immediately.

## 7. `style-guide/AI-COPY-PASTE.md`
Universal prompt for ChatGPT, Claude, Gemini, or another AI.

Use it by copying the contents into a new AI conversation. After GitHub Pages is live, replace the placeholder guide URLs with the final public URLs.

## 8. `style-guide/prompts.md`
Reusable Region South prompt library.

Use it when creating common Region South graphics and when you want consistent user prompting for Light/Dark Mode, Source, Date, and embargo status.

## 9. `style-guide/examples.html`
Examples Gallery website page.

Use it to view approved examples and legacy references together.

## 10. `style-guide/examples/`
Contains individual approved/reference visual examples.

Use these files as visual models. The approved HTML pages are the strongest standards references because their charts, terminology, colors, and authentic logo assets are controlled directly.

## 11. `style-guide/assets/`
Contains canonical logos and supporting visual assets used by the site.

Do not replace `RS-logo.png` or `LAUSD_seal.png` with AI-generated approximations.

## 12. `style-guide/FINAL-VALIDATION-REPORT.md`
Records what was validated and which examples are approved production examples versus illustrative layout examples.

Use it when reviewing whether a future change requires revalidation.

## 13. `style-guide/DEPLOYMENT-INSTRUCTIONS.md`
Step-by-step GitHub Pages publishing instructions.

Use it when you are ready to put the guide online.

---

## Recommended first action
Download the final ZIP, extract it, read this file, then follow `DEPLOYMENT-INSTRUCTIONS.md` to publish the `/style-guide/` folder to the existing Region South GitHub repository.
