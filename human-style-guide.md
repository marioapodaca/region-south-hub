# Region South Visual Style Guide
## Human-Facing Guide — Draft v1.0

### Purpose
The Region South visual system is a presentation and communication framework designed to make instructional and data communications consistent, recognizable, student-centered, and aligned with LAUSD branding.

The system is built around six priorities:
1. Data accuracy
2. Brand compliance
3. Readability
4. Correct subject identity
5. Student-centered representation
6. Aesthetic polish

---

## 1. Brand Foundation

Region South graphics should feel:
- Professional
- Data-driven
- Student-centered
- Modern
- Optimistic
- Clear

The Region South identity should function within the LAUSD brand environment rather than replace it.

## 2. Approved Display Modes

Region South supports both **Light Mode** and **Dark Mode**.

### Light Mode
Best for:
- print
- dense analytical charts
- regional comparisons
- detailed data tables
- maximum color contrast

Typical treatment:
- white or soft-white background
- navy text
- light chart cards
- subject colors displayed directly on light plotting areas

### Dark Mode
Best for:
- presentations
- executive dashboards
- title slides
- hero graphics
- student photography
- large-screen display

Typical treatment:
- Region South navy background
- white primary text
- light-blue secondary text
- dark panels
- white/light chart plotting areas where contrast or LAUSD color restrictions require them

### Required user choice
If a user has not specified a mode, ask whether they want **Light Mode** or **Dark Mode**. If they are unsure, recommend one and obtain confirmation before generating the final visual.

## 5. Typography

Primary typeface: **Poppins**

Recommended hierarchy:
- Major title: Poppins Bold / ExtraBold
- Section heading: Poppins Bold
- Subtitle: Poppins Medium
- Chart title: Poppins SemiBold
- Large metric: Poppins Bold / ExtraBold
- Body: Poppins Regular
- Chart labels: Poppins Medium
- Footer/source: Poppins Regular

Digital body alternative: Open Sans  
Fallback: Arial

Avoid Thin/ExtraLight weights in presentation graphics.

## 6. Photography and Student Representation

Region South student imagery should be:
- authentic
- academically engaged
- age-appropriate
- diverse
- natural rather than posed
- visually subordinate to the data story

Students should be shown actively learning.

### ELA
Preferred activities:
- reading
- annotating
- discussing text
- writing in response to reading

Preferred icon:
- open book
- LAUSD Orange #FF4D00

### Math
Preferred activities:
- solving equations
- using calculators
- graphing
- collaborative problem-solving

Preferred icon:
- calculator
- LAUSD Navy #00237A

### Science
Preferred activities:
- conducting experiments
- measuring liquids
- recording observations
- discussing results

Preferred icon:
- beaker, flask, or microscope
- LAUSD Green #00602D

When a green Science icon appears on a navy slide, place it in a white/light container.

## 8. Terminology

### Proficient + Advanced
Preferred full name: **Proficient + Advanced**  
Space-constrained form: **P+A**

Do not display **PoA** in Region South-facing graphics.

### Distance from Proficiency
Preferred full name: **Distance from Proficiency**  
Abbreviation: **DFP**

### Science Points
Preferred full name: **Science Points**  
Space-constrained form: **SP**

### Required definitions
If P+A, DFP, or SP appears in a visual, define it somewhere in that same visual.

Examples:
- P+A = Proficient + Advanced
- DFP = Distance from Proficiency
- SP = Science Points

## 9. Data Visualization Standards

### P+A
- Higher is better.
- Use percentage formatting consistently.
- Describe differences in percentage points when comparing percentages.

### DFP
- Higher is better.
- Values closer to zero are closer to proficiency.
- Positive values are above proficiency.
- Use 0 as the Proficiency benchmark when relevant.
- Never reverse the axis just to make improvement appear upward.

### SP
- Range: 0–100.
- Proficiency benchmark: 65.
- Label benchmark **Proficiency**.
- Do not use the phrase **Proficiency Floor**.

### Regional comparisons
- South receives the strongest visual emphasis.
- Other regions remain fully legible.
- Use the locked regional palette.
- Use the same region color across all charts in the same graphic.

### Cohort bars
For SBA/CAASPP cohort-change graphics:
- use the subject color family as the primary encoding;
- use bar direction above/below zero to show sign;
- use green/red only as secondary semantic callouts;
- interpret educational meaning, not mathematical sign alone.

## 10. Growth, Trend, and Acceleration

Use these terms precisely.

**Improvement**  
Performance moved in a favorable direction.

**Growth**  
Improvement observed over multiple periods.

**Average annual change**  
Endpoint-based annual rate.

**Linear trend slope**  
Regression-based rate using all observations.

**Acceleration**  
The rate of improvement itself is increasing.

Do not use acceleration as a synonym for ordinary growth.

Words such as **largest**, **strongest**, **fastest**, **highest**, **lowest**, and **most improved** must specify the comparison period.

---

## 11. Preliminary and Embargoed Data

If an actual value is restricted:
- do not show the value;
- do not position a point at an inferable location;
- do not use a precisely scaled arrow endpoint;
- use a direction-only treatment or separate Preliminary Trend zone.

Preferred wording:
**Preliminary results remain embargoed and are shown only as a generalized trend.**

For stronger internal treatment:
**PRELIMINARY — INTERNAL USE ONLY**

---

## 12. Footer and Metadata Standards

Preferred footer:
- Left: Region South / LAUSD branding
- Center: definitions, methodology, embargo note
- Right: source and date

### Required user prompts
If Source is missing, ask for it and offer omission if it is not pertinent.

If Date is missing, ask for a download/data-as-of date and offer omission if it is not pertinent.

Never invent a source or date.

Approved date labels:
- Data as of
- Downloaded
- Results through

## 14. Approved Example Workflow

A graphic becomes an **Approved Example** only after post-production review.

Check:
- authentic logos
- Poppins typography
- numeric accuracy
- correct subject and regional colors
- source/date
- abbreviation definitions
- embargo compliance
- accessibility and contrast

AI-generated compositions may be used as design drafts, but brand-critical elements must be verified before publication.
