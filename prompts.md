# Region South Prompt Library v1.1

## Required pre-generation prompt

Before finalizing any Region South data visual, resolve the following:

1. **Display Mode** — Light or Dark
2. **Source** — provide or omit
3. **Date** — provide or omit
4. **Preliminary/Embargo Status** — when relevant

If Display Mode is missing, ask:
"Would you like this graphic in Light Mode or Dark Mode? Light Mode works best for print, dense charts, detailed comparisons, and maximum color contrast. Dark Mode works best for presentations, executive dashboards, hero graphics, and student photography. If you are unsure, I can recommend one."

If Source and/or Date are missing, ask for them and explicitly offer omission if not pertinent.

Do not silently choose a display mode.
Do not invent a source.
Do not invent a date.

## RS-01 — Hero Data
Create a Region South RS-01 Hero Data graphic for [SUBJECT].

Use age-appropriate students actively engaged in [SUBJECT ACTIVITY] on the left.
Use the main data visualization in the center.
Use RS-C01 Key Takeaway on the right.
Use Poppins typography.
Use the correct subject color family.
Define every abbreviation used.
Use authentic Region South/LAUSD assets when available.

Source: [SOURCE / OMIT]
Date: [DATE / OMIT]

---

## RS-02 — Regional Comparison
Create a Region South RS-02 Regional Comparison graphic for [GRADE] [SUBJECT].

Compare Region East, North, South, and West.
Use the locked regional colors for the subject.
Show P+A on the left and DFP or SP in the center.
Use "The Region South Story" on the right.
Region South should receive the strongest visual emphasis without suppressing other regions.
Define P+A, DFP, and/or SP somewhere in the visual.
Use Poppins.

Source: [SOURCE / OMIT]
Date: [DATE / OMIT]

---

"What source should be listed, and what download/data-as-of date should appear? If either item is not pertinent, I can omit it."
